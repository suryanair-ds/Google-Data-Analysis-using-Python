📊 Google Search Trend Analysis using PyTrends

This project analyzes Google search data for any keyword chosen by the user. Using the PyTrends API, it fetches real-time search interest, identifies regions with the highest search volume, and visualizes the insights using multiple data-science libraries.

🔍 Project Overview

- Takes a keyword input from the user
- Uses PyTrends to fetch Google Trends data
- Identifies top regions with the highest search interest
- Performs exploratory data analysis (EDA)

Visualizes trends and patterns using:
Matplotlib
Seaborn
Plotly
Pandas


🛠 Technologies Used
Python
PyTrends
Pandas
Seaborn
Matplotlib

📌 Features

Keyword-based Google Trends data extraction
Interest by region analysis
Trend visualization with interactive and static plots
Clean and readable Jupyter Notebook workflow

Data-driven insights for any search term
